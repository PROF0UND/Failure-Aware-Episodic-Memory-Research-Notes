- **Task list** — a fixed list of Cybench task paths (start with a subset; you and I can pick ~10-15 spanning difficulty/category).
- **Two conditions per task** — `no_memory` and `faem`, each run separately, same task, same model.
- **Per-task hard timeout** — not just an iteration cap, but a wall-clock kill (e.g. 15-20 min per run) so a hung LLM call doesn't stall the whole night. Use a subprocess timeout, not just trusting the iteration cap to save you.
- **Try/except around each task** — log the failure and move to the next task rather than crashing the whole script.
- **Resumability** — before running a task+condition, check if its log already exists; skip if so. This means if the script dies at 2am, you restart it and it picks up where it left off instead of redoing everything.
- **Progress log** — a simple running text file (`progress.log`) appended after each task/condition finishes, so you can check status in the morning without parsing JSON logs.
- **A separate aggregation script**, run _after_ the batch completes, that reads all the logs and produces your comparison table (solve/subtask score, branch diversity, backtrack frequency, time-to-pivot, Type A/B counts) — keep this decoupled from the runner so you can re-run aggregation without re-running experiments.
