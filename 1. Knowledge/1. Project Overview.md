## Introduction
This project is focused on helping develop smarter [[penetration testing]] agents. Presently, if an AI agent uses a method that leads to failure, it forgets about it and uses the same method later. This leads to a loss in resources and time. 

This project will focus on giving the AI agent a smarter memory to track these failures and successes to improve efficiency during [[penetration testing]],so that when it hits a dead end or a failed approach, it stores that experience in a structured way and actually learns to avoid it in the future. 

An in-depth and professional outline of this document can be found in the [[6. Proposal Document]].

## Why is this useful?
This project is useful in the following ways:
1. Good [[penetration testing]] agents are faster and cheaper, however, these agents still make a lot of mistakes. Realistic infrastructure is made to trap such agents into loops and render them redundant.
2. This project acts as a stepping stone to to help agents handle these deceptions.

In essence: 
*If we can teach AI security agents to stop repeating their own mistakes, we get faster, cheaper, and more reliable automated security testing — which matters as cyber threats scale faster than human defenders can.*

## What is [[episodic memory]]?
Episodic memory is a term borrowed from *cognitive psychology*. In humans, it refers to your memory of specific past experiences — not general facts, but actual episodes you lived through.

For example:

- Knowing that "fire is hot" is *semantic memory* (general knowledge)
- Remembering the specific time _you_ burned your hand on a stove is *episodic memory* (a personal experience)

The key feature is that episodic memory is *tied to context* — what happened, when, where, and what the outcome was.
