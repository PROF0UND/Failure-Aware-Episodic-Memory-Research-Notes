Penetration testing (or pen testing) is a security exercise where a cyber-security expert attempts to find and exploit vulnerabilities in a computer system. The purpose of this simulated attack is to identify any weak spots in a system’s defenses which attackers could take advantage of.

This is like a bank hiring someone to dress as a burglar and try to break into their building and gain access to the vault. If the ‘burglar’ succeeds and gets into the bank or the vault, the bank will gain valuable information on how they need to tighten their security measures.

[Source](https://www.cloudflare.com/learning/security/glossary/what-is-penetration-testing/)

---

### How it typically works
It generally follows a sequence of phases:
1. **Reconnaissance** — gather information about the target (what services are running, what software versions, who works there, etc.)
2. **Scanning** — probe the target more actively for open ports, misconfigurations, known vulnerabilities
3. **Exploitation** — attempt to actually break in using discovered weaknesses
4. **Post-exploitation** — once inside, see how far you can go (escalate privileges, move laterally, access sensitive data)
5. **Reporting** — document everything found so the organization can fix it
