Firstly, it is important to setup a baseline agent. The project's different memory strategies run on a penetration testing agent. Once we have an agent capable of tool calls and exploitation, the different memory strategies can be applied to it. 

---
The project requires:
1. Python 3.10+
2. Git
3. Kali
	1. You can use a [[WSL version of Kali]] as that is convenient.

---

## Initial Testing:
1. After you have [[WSL version of Kali]] setup, go ahead and [[clone the repository]].
2. Use VS Code to open the cloned repo
	1. On VS Code, click the tiny icon  on the bottom left and select open WSL with Kali distro.
3. Create a `.env` file (keep it empty for now)
```shell
touch .env
```
7. Install the dependencies:
```shell
sudo apt update && sudo apt install -y python3-pip python3-venv

# Make a virtual environment
python3 -m venv venv
source venv/bin/activate

# Install requirements
pip install -r requirements.txt

# Install Ollama
sudo apt-get install -y zstd
curl -fsSL https://ollama.com/install.sh | sh
```
8. [Optional] Install [[Docker]]
9. Use a test LLM:
```shell
ollama pull llama3.2
```
9. Now update agent files (eg: `agent_v1_no_tools.py`) to use llama3.2
	1. Find the line:
	```python
	llm = ChatOllama(
	    model="devstral-2:123b-cloud",
	    temperature=0.8,
	)
	```
	2. Change it to:
	```python
	llm = ChatOllama(
	    model="llama3.2",
	    temperature=0.8,
	)
	```
10. Run it:
```shell
python3 agent_v1_no_tools.py
```

## Baseline Model:
The [[Agent v2]] will be used as the baseline model. v2 is the right foundation because it's fully local, fully reproducible, and has no external dependencies. Your three memory variants (no memory, raw replay, FAEM) will all be built on top of v2's architecture
