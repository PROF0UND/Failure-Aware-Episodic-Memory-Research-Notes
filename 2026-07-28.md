**PentestGPT v2** is a different, much newer system that was _built to fix a different problem_. Its authors found the real blocker wasn't lack of memory — it was that agents can't judge how hard a path is (Type B failures: agent doesn't know if a branch is 3 steps or 30 steps away, doesn't know when to stop scanning and start exploiting). So they built TDA — four difficulty signals — and wired it into a tree-search algorithm (EGATS) that prunes bad branches in real time.

As part of that, they _also_ added a Memory Subsystem — but it's not FAEM-style failure memory. It's structured state (attack tree branches, summaries) kept outside the LLM's context window so the agent doesn't forget what it already tried _during one long engagement_. It's solving "context window overflow," not "learning from past failures across episodes."

So the difference in one line: **v1 has no memory. v2 has memory, but it's a different kind of memory solving a different problem than FAEM.**
