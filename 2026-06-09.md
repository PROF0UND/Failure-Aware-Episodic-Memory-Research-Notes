### 1. The Problem
- LLM agents doing pentesting get stuck in loops — retry the same failed commands, waste tokens
- They have no mechanism to learn from failure _within_ a run
- FAEM asks: what if the agent explicitly remembered its failures?
- Memory contains what happened and a small reflection.

---

### 2. The Paper — Reflexion (NeurIPS 2023)
- Core idea: use _verbal_ feedback on each failure.
	- Agent reflects on failure in natural language 
	- → stores that reflection 
	- → uses it next time
- What I used: the self-reflection mechanism 
	- → directly implemented in `_generate_reflection()` in `faem.py`
- Your extension: applied to pentesting domain, added phase labels and deterministic failure detection

#### FAEM memory Entry:
```python
@dataclass
class FailureMemoryEntry:
    phase: str        # "recon"|"vulnerability_analysis"|"exploitation"
    action: str       # exact command run
    outcome: str      # tool output truncated to 500 chars
    success: bool     # from deterministic evaluator
    reflection: str   # LLM-generated prose (empty string if success=True)
    step: int
    timestamp: str    # ISO format
```

#### Reflection Generator:
```python
    def _generate_reflection(self, phase: str, action: str, outcome: str) -> str:
        prompt = (
            "You are a penetration testing assistant reviewing a failed action.\n\n"
            f"Phase: {phase}\n"
            f"Command attempted: {action}\n"
            f"Output received: {outcome}\n\n"
            "In 2-3 sentences explain:\n"
            "1. Why this action failed\n"
            "2. What specific pattern to avoid repeating\n"
            "3. What to try instead\n\n"
            "Be concrete. Reference the exact command syntax or flag that caused the failure."
        )
        try:
            resp = requests.post(
                "http://localhost:11434/api/generate",
                json={"model": self._model, "prompt": prompt, "stream": False},
                timeout=30,
            )
            resp.raise_for_status()
            return resp.json().get("response", "").strip()
        except Exception:
                print(f"[FAEM] reflection failed: {e}")
                return ""
```

### 3. The Benchmark — CyberBench Challenges

Three HackTheBox web challenges, run in Docker. Used Claude to help shortlist these challenges.
- **KORP Terminal** — 
	- SQL injection + hash cracking 
	- → tests chained multi-step exploitation
- **TimeKORP** 
	- — OS command injection 
	- → tests precise payload crafting
- **Labyrinth Linguist** — 
	- SSTI with dynamic flag path 
	- → tests adaptability
- Why these three: all web category, increasing complexity, different vulnerability classes
